# NameScope CLI

Published `npx` package for [NameScope](../../README.md), free local-first software project-naming intelligence.

```bash
npx namescope find "a fast open-source database migration tool"
npx namescope check taskforge
npx namescope mcp
```

No account, API key, payment, wallet, hosted service, Docker installation, or model is required. See repository README for provider, privacy, scoring, MCP, and legal limitations.
