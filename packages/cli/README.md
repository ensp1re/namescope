# Nametagged CLI

Published `npx` package for [Nametagged](../../README.md), free local-first software project-naming intelligence.

```bash
npx nametagged find "a fast open-source database migration tool"
npx nametagged check taskforge
npx nametagged mcp
```

No account, API key, payment, wallet, hosted service, Docker installation, or model is required. See repository README for provider, privacy, scoring, MCP, and legal limitations.
